Sistemas Numéricos - Lista 04

Problema 27:

O Índice de Desenvolvimento Humano (IDH) é uma medida usada para classificar os países pelo seu grau de desenvolvimento. Para seu cálculo, são levados em consideração a expectativa de vida ao nascer, tempo de escolaridade e renda per capita, entre outros. O menor valor deste índice é zero e o maior é um. Cinco países foram avaliados e obtiveram os seguintes índices de desenvolvimento humano: o primeiro país recebeu um valor X, o segundo √X, o terceiro X1/3, o quarto X² e o último X³. Nenhum desses países zerou ou atingiu o índice máximo.

Qual desses países obteve o maior IDH?

Solução 26:

Os valores de IDH dos cinco países são:

  • Primeiro país: X
  • Segundo país: √X = X1/2
  • Terceiro país: X1/3
  • Quarto país: X²
  • Quinto país: X³

Sabemos que 0 < X < 1, pois nenhum país atingiu o valor máximo (1) nem zerou. Como estamos trabalhando com potências de uma base X entre 0 e 1, quanto maior o expoente, menor será o resultado.

Assim:
X3 < X2 < X < X1/2 < X

Logo, o maior valor entre os índices é X1/3, que corresponde ao terceiro país.
